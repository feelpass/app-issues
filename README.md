# App Issues

A place to report and discuss issues for yp's apps (Type, Type History, Cloak, and more).

## How to file an issue

1. Go to **Issues → New issue** and pick a template:
   - Bug report
   - Feature request
   - Question & discussion
2. Choose the app under **App** — the matching `app: …` label is added automatically.
3. Drag screenshots or videos into any text field to attach them.

## Filter by app

| App | Label |
|---|---|
| Type | `app: Type` |
| Type History | `app: Type History` |
| Cloak | `app: Cloak` |
| Other | `app: Other` |
