# App Issues

yp의 앱(Type · Type History · Cloak · Type Keyboard iOS 등) 이슈를 등록하고 이야기하는 곳이에요.
A place to report and discuss issues for yp's apps (Type, Type History, Cloak, Type Keyboard iOS, and more).

## 이슈 쓰는 법 / How to file an issue

1. **Issues → New issue**에서 양식을 고르세요. / Pick a template under **Issues → New issue**.
   - 버그 신고 / Bug report
   - 기능 제안 / Feature request
   - 질문·논의 / Question & discussion
2. **앱 / App**에서 해당 앱을 고르면 `app: …` 라벨이 자동으로 붙어요. / Choosing an app adds the matching `app: …` label automatically.
3. 스크린샷·영상은 입력란에 끌어다 놓으면 첨부돼요. / Drag screenshots or videos into any text field.
